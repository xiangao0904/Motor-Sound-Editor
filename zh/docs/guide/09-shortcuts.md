# 快捷键

Motor Sound Editor 目前支持以下高频快捷键与交互约定。

## 全局编辑快捷键

以下快捷键在编辑器页面中可用：

- `Space`：播放 / 暂停预览
- `Ctrl+S`：保存
- `Ctrl+Shift+S`：另存为
- `Ctrl+Z`：撤销
- `Ctrl+Y`：重做
- `Ctrl+Shift+Z`：重做
- `Ctrl+D`：清除当前选择
- `Delete`：删除当前选中的关键帧点


## 运行模式快捷键

用于快速切换当前模拟运行状态：

- `W`：向上切换运行模式
  - `brake -> coasting -> traction`
- `S`：向下切换运行模式
  - `traction -> coasting -> brake`

## 鼠标与修饰键约定

- `Ctrl + 滚轮`：以鼠标当前位置为锚点进行横向缩放
- `Shift + 滚轮`：横向滚动编辑区域
- 拖动关键帧时按住 `Shift`：按步进吸附
- 拖动关键帧时按住 `Ctrl`：按网格吸附
