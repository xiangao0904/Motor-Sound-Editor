# 音频编辑器（1.3）

> 本页记录开发中的 1.3 功能。教程暂未更新。

从项目编辑器中选中一条已分配音频的轨道，打开 **Audio Editor**。修改后点击 **Save to Project**，处理结果会作为当前轨道的音频写回项目；之后仍需保存 `.msep`。顶部的 Undo、Redo 可回退音频编辑步骤。按 `Space` 播放或暂停当前预览；在输入框中打字时不会触发播放。

## Loop Maker

拖动波形中的起点、终点或整段选区，确定循环范围。播放模式可在原音、当前结果和循环段之间切换。需要精确定位时可放大波形，查看两端细节，并用 **Sample Nudge** 对起点或终点逐采样调整。逐采样按钮每次只移动一个采样点，适合最后的细调。

循环播放会持续跨过接缝。用两端细节视图检查波形相位和音量，减少接缝处的爆音。处理好后应用结果。

## Pitch Flattener

上方显示原音频谱，下方显示拉平结果。黄色路径描述**原音的音高走向**：在同一条可见谐波纹路上选起点和终点，再拖动端点使路径贴合纹路。路径可切换 **Straight** 直线和 **Bézier** 曲线；后者可拖动控制柄。处理结果会根据整条路径的频率变化进行校正，目标是让选中的音高走向尽量水平。

编辑路径时先看图形反馈；确认后更新预览。通过 **Current / Result** 和 **Play** 对照听感，再应用结果。路径越贴近实际谐波，音高校正越可靠。

## Spectral Editor

频谱工具用于削弱选定的频率内容。**Region** 在时间和频率上框选一块区域；**Draw Path** 沿声音纹路画线。**Reduction** 控制衰减量，**Path width** 控制路径作用的频率带宽。下方结果视图和 **Current / Result** 可用于对比。可撤销最近一次选择或清空所有选择，确认后应用结果。

这个工具适合处理局部机械杂音、固定频段噪声和短时异响。它会衰减选中的频率内容，可能同时影响邻近的目标音；建议从较小衰减开始试听。
